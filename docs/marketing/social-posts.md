# Telegram / WhatsApp Intro Posts

Plain text, ready to copy-paste into a group or a direct message. `*asterisks*`
mark bold — WhatsApp renders these automatically; Telegram does not auto-bold
typed asterisks in a normal chat, so on Telegram they'll show as literal
characters unless you reapply bold manually via the formatting menu. Left
them in anyway since they still read as intentional emphasis either way.

URLs are plain (not markdown links) since neither app auto-links `[text](url)`
markdown syntax from a pasted message — only raw URLs auto-linkify.
